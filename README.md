# 德高农牧 · 微信小程序（Alpha）

济南德高农牧科技有限公司的官方小程序演示版：官网替代 + 产品商城 + AI 选品顾问，支持中英文切换。

## 功能

| 页面 | 内容 |
|---|---|
| 首页 | 品牌主视觉、AI 选品入口、按养殖品种（猪/禽/反刍/水产）的方案、主推产品、产品系列、资质认证、联系方式 |
| 产品中心 | 14 个系列、24 个规格；支持搜索、按类别和动物筛选 |
| 产品详情 | 规格切换、功效、参数、参考添加量、加入采购单、立即下单、电话询价 |
| AI 选品 | 客户描述养殖问题，系统推荐产品组合与用量；可一键加入采购单 |
| 采购单 / 下单 / 订单 | 完整的下单流程（Alpha 版订单只保存在本机） |
| 关于德高 / 联系我们 | 公司简介、发展历程、资质荣誉、在线留言 |
| 我的 | 订单、采购单、语言切换（简体中文 / English） |

## 预览方法

1. 安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)，用微信扫码登录。
2. 选「导入项目」，目录选本文件夹 `DEGAO_platform`。AppID 处点「测试号」（不要用游客模式，游客模式不能在手机上预览）。
3. 导入后左侧模拟器即可看到效果。
4. 手机预览：点工具栏「预览」，用微信扫二维码。

## 网页预览版

不装微信也能看：<https://qiranjia1996.github.io/DEGAO_platform/>（用微信打开链接即可）。

- `web/` 把 `miniprogram/` 原样跑在浏览器里（模拟 Page / Component / wx API），页面和数据与小程序同一份，不用单独维护。
- 推送到 `main` 后，GitHub Actions 自动打包并发布到 GitHub Pages。
- 本地打包：`node web/build.js`，然后用浏览器打开 `web/dist/index.html`。
- 网页版的采购单和订单保存在浏览器本地，同样只用于演示。

## 视觉素材

配色、Logo 和产品图风格取自德高新包装。素材源文件在 `design/`，改完后重新生成：

- `node design/render.js`：把 `design/brand/`、`design/icons/` 里的 SVG（Logo、标签栏图标、动物图标）渲染成 `miniprogram/images/` 下的 PNG（需要本机装有 Chrome）
- `node design/brush-font.js`：重新生成书法标题字体 `miniprogram/styles/brush-font.wxss`。字体是马善政毛笔楷书（开源，SIL OFL），只保留标题用到的字。**改了标题文案后要重新运行**，否则新加的字会显示成宋体（需要 python3 + fonttools）

## AI 选品

- 默认使用**本地智能匹配**（不联网也能用，适合演示）。
- 接入大模型：在 `miniprogram/config.js` 填入 DeepSeek（或通义千问等 OpenAI 兼容接口）的 API Key。开发者工具中勾选「详情 → 本地设置 → 不校验合法域名」；手机预览时需打开「开发调试」。
- 正式上线前必须把大模型调用移到后端（云开发云函数或自建服务器），不能把密钥放在前端。

## 数据来源与待确认事项

- 公司信息、产品系列和规格：德高官网 degaonongmu.com（网页存档 2024-12 / 2025-02）、企查查/爱企查/天眼查公开信息、山东省政府公示文件。
- **需要德高确认**：
  - 产品价格：目前全部是演示价格
  - 各产品的参考添加量和功效描述：目前是行业通用参考，需技术部审核
  - 大蒜素、牛至双酚、酵母细胞壁多糖、霉毒克、葡萄糖氧化酶、胍基乙酸的具体含量规格
  - 产品实拍图、资质证书扫描件、Logo 源文件
  - 问答选品的 29 个推荐组合和推荐语（`miniprogram/data/decision-tree.js`）
  - 二甲酸钾仔猪用量：目录写的是 6–12 kg/t，但欧盟 EFSA（2021）认定的安全上限是 6 kg/t，且没有安全余量
  - 霉毒克的具体成分：推荐语引用的是黏土类和「黏土 + 酵母」吸附剂的研究，需要确认与霉毒克的成分是否一致
  - 目录里有几项功效说法缺少文献支持，见下方「研究文献」

## 研究文献

问答选品的推荐语和产品详情页的「研究依据」引用了 48 篇公开文献（`miniprogram/data/references.js`）。每条 DOI 都经 Crossref 核对，「研究发现」只写论文摘要里有的结论。这些是该类成分的公开研究，不是对德高产品的测试，页面上也有同样的说明。

- `node scripts/check-refs.js`：在线核对全部 DOI、年份和标题
- `node scripts/test-tree.js --print`：检查决策树（每条路径都能走到结果、产品适用动物、每个推荐产品至少引用一篇文献、中英文齐全），并列出全部路径

检索时**没有找到文献支持**的说法（目录里的功效文字暂未修改，推荐语里已避开）：
- 二甲酸钾「降低胃肠 pH」：肉鸡试验中肠道 pH 没有变化；生长猪的消化率试验也没有差异
- γ-氨基丁酸：只有肉鸡热应激的研究，猪、蛋鸡、反刍动物上没有找到。推荐语里已注明「研究来自肉鸡」
- 半胱胺用于水产，牛至用于反刍和水产，单宁酸用于犊牛，葡萄糖氧化酶用于猪
- 大蒜素作为水产诱食剂（只找到抗病研究）；甜菜碱诱食只找到罗氏沼虾一篇

## 目录结构

```
miniprogram/
  app.*                 全局配置与设计系统（配色、按钮、卡片）
  config.js             AI 大模型配置
  data/catalog.js       产品目录（系列、规格、功效、用量、演示价格）
  data/company.js       公司信息、资质、发展历程、联系方式
  utils/i18n.js         中英文文案
  utils/advisor.js      AI 选品（大模型 + 本地匹配）
  utils/tree.js         问答选品（决策树）
  data/decision-tree.js 问答选品的问题、推荐组合和推荐语
  data/references.js    研究文献
  utils/store.js        采购单与订单
  components/           产品视觉卡、产品卡片
  pages/                10 个页面
```
