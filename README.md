# 德高农牧 · 微信小程序（Alpha）

济南德高农牧科技有限公司的官方小程序演示版：官网替代 + 产品商城 + AI 选品顾问，支持中英文切换。

## 功能

| 页面 | 内容 |
|---|---|
| 首页 | 品牌主视觉、AI 选品入口、按养殖品种（猪/禽/反刍/水产）的方案、六大方向各一个主推产品、六大产品方向、资质认证、联系方式 |
| 产品中心 | 19 个系列、35 个规格（与 2026 年 10 月产品目录表一致）；按六大方向和动物筛选，支持搜索 |
| 产品详情 | 产品介绍、核心功效、作用原理、按动物分组的应用场景（带文献编号）、如何选择规格、规格参数、使用要点、常见问题、研究依据；加入采购单、立即下单、电话询价 |
| AI 选品 | 客户描述养殖问题，系统推荐产品组合与用量；可一键加入采购单 |
| 采购单 / 下单 / 订单 | 完整的下单流程（Alpha 版订单只保存在本机） |
| 关于德高 / 联系我们 | 公司简介、发展历程、资质荣誉、在线留言 |
| 我的 | 订单、采购单、语言切换（简体中文 / English） |

## 预览方法

1. 安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)，用微信扫码登录。
2. 选「导入项目」，目录选本文件夹 `DEGAO_platform`。AppID 处点「测试号」（不要用游客模式，游客模式不能在手机上预览）。
3. 导入后左侧模拟器即可看到效果。
4. 手机预览：点工具栏「预览」，用微信扫二维码。

## 网页预览版

不装微信也能看：<https://qiranjia1996.github.io/DEGAO_platform/>（用微信打开链接即可）。

- `web/` 把 `miniprogram/` 原样跑在浏览器里（模拟 Page / Component / wx API），页面和数据与小程序同一份，不用单独维护。
- 推送到 `main` 后，GitHub Actions 自动打包并发布到 GitHub Pages。
- 本地打包：`node web/build.js`，然后用浏览器打开 `web/dist/index.html`。
- 网页版的采购单和订单保存在浏览器本地，同样只用于演示。

## 视觉素材

配色、Logo 和产品图风格取自德高新包装。素材源文件在 `design/`，改完后重新生成：

- `node design/render.js`：把 `design/brand/`、`design/icons/` 里的 SVG（Logo、标签栏图标、动物图标）渲染成 `miniprogram/images/` 下的 PNG（需要本机装有 Chrome）
- `node design/brush-font.js`：重新生成书法标题字体 `miniprogram/styles/brush-font.wxss`。字体是马善政毛笔楷书（开源，SIL OFL），只保留标题用到的字。**改了标题文案后要重新运行**，否则新加的字会显示成宋体（需要 python3 + fonttools）

## AI 选品

- 默认使用**本地智能匹配**（不联网也能用，适合演示）。
- 接入大模型：在 `miniprogram/config.js` 填入 DeepSeek（或通义千问等 OpenAI 兼容接口）的 API Key。开发者工具中勾选「详情 → 本地设置 → 不校验合法域名」；手机预览时需打开「开发调试」。
- 正式上线前必须把大模型调用移到后端（云开发云函数或自建服务器），不能把密钥放在前端。

## 数据来源与待确认事项

- 产品、规格、包装和添加量：《济南德高农牧科技有限公司产品目录表》（2026 年 10 月版，即 `产品目录表(3).docx`，原件不入库）。`node scripts/test-catalog.js` 会逐条核对网站规格与目录表是否一致。
- 公司信息：德高官网 degaonongmu.com（网页存档 2024-12 / 2025-02）、企查查/爱企查/天眼查公开信息、山东省政府公示文件。
- 与上一版相比下架了二甲酸钾、牛至双酚、葡萄糖氧化酶，新增增肌王、GAMT 酶、黑黄金、包被蛋氨酸、包被赖氨酸、包被氯化胆碱、包被复合酶、包被复合维生素、半胱胺螯合锌。
- **需要德高确认**：
  - 产品价格：目录表里出厂价、指导价都是空的，网站上全部是演示价格
  - 复配产品的成分：增肌王、GAMT 酶（3 个版本）、黑黄金、包被复合酶、包被复合维生素、霉毒克-100。这几个在网站上标注「成分待确认」，只写通用介绍，不引用文献，也不进入问答选品和 AI 推荐（`catalog.js` 里 `pending: true`）。拿到成分后再查文献、补写详细介绍
  - GAMT 酶：名称是「胍基乙酸甲基转移酶」，需要确认产品里实际是什么成分、如何起作用
  - 半胱胺螯合锌：没有找到这种形式的公开研究，目前只引用半胱胺本身的研究
  - 全部产品介绍、应用场景、使用要点、常见问题，以及问答选品的 31 个推荐组合（`miniprogram/data/decision-tree.js`），需技术部审核
  - 产品实拍图、资质证书扫描件、Logo 源文件
- **目录用量与文献剂量的对比**（目录用量没有改动，以下请技术部判断）：
  - 一致：98% γ-氨基丁酸 25–50 g/t（约 25–49 mg/kg）与猪（20–30 mg/kg）、蛋鸡（50 mg/kg）研究一致；30% 包被半胱胺 300 g/t（约 90 mg/kg 盐酸盐）与育肥猪研究（70 mg/kg）接近；98% 胍基乙酸 300–600 g/t 与猪的研究（300–600 mg/kg）一致
  - 丁酸钠 7 个规格都是 250–1000 g/t，但含量从 98% 到 30%，同样用量下有效成分相差约 3 倍。网站上已建议低含量包被产品取中上限
  - 10% 胆汁酸 100–300 g/t 只相当于 10–30 mg/kg 胆汁酸，低于研究中的 60–80 mg/kg
  - 包被蛋氨酸、赖氨酸、氯化胆碱按「g/吨饲料」给量，奶牛研究按每头每天或占干物质的比例给量（如胆碱每天约 13 g、蛋氨酸约 0.1% 干物质）。按常见采食量换算，目录用量可能偏低，建议补充「每头每天」的用法
  - 三丁酸甘油酯在对虾研究中用到 10 g/kg，远高于目录的 500–1000 g/t
  - 50% 包被胍基乙酸 300–600 g/t 只提供 150–300 mg/kg 胍基乙酸，牛羊研究用的是 0.6–1.0 g/kg
  - 半胱胺在种鸡上（400 mg/kg）提高产蛋率，但后代母雏体重偏低，网站上已提示种鸡慎用

## 研究文献

产品详情页和问答选品引用了 61 篇公开文献（`miniprogram/data/references.js`），本次按新目录逐个系列重新检索（Europe PMC + Crossref），删除了下架产品和单纯黏土类脱霉剂的文献，新增了过瘤胃蛋氨酸/赖氨酸/胆碱、包被胍基乙酸、γ-氨基丁酸（猪、蛋鸡、奶牛）等研究。每条 DOI 都经 Crossref 核对，「研究发现」只写论文摘要里有的结论，包括不利结果（如单宁酸肉鸡全程使用会降低生长）。这些是该类成分的公开研究，不是对德高产品的测试，页面上也有同样的说明。

- `node scripts/check-refs.js`：在线核对全部 DOI、年份和标题
- `node scripts/test-tree.js --print`：检查决策树（每条路径都能走到结果、产品适用动物、不推荐成分待确认的产品、每个推荐产品至少引用一篇文献、中英文齐全），并列出全部路径
- `node scripts/test-catalog.js`：核对规格与目录表一致，以及各系列介绍、应用场景、文献引用是否齐全

检索时**没有找到文献支持**的说法（网站上已避开或注明）：
- 大蒜素在家禽上的研究（只找到大蒜粉、或在饮水中使用的研究），网站上家禽没有写应用场景
- 三丁酸甘油酯、单宁酸在反刍动物上；半胱胺在水产上
- 半胱胺螯合锌、各复配产品

## 目录结构

```
miniprogram/
  app.*                 全局配置与设计系统（配色、按钮、卡片）
  config.js             AI 大模型配置
  data/catalog.js       产品目录（六大方向、系列、规格、作用原理、应用场景、使用要点、常见问题、用量、演示价格）
  data/company.js       公司信息、资质、发展历程、联系方式
  utils/i18n.js         中英文文案
  utils/advisor.js      AI 选品（大模型 + 本地匹配）
  utils/tree.js         问答选品（决策树）
  data/decision-tree.js 问答选品的问题、推荐组合和推荐语
  data/references.js    研究文献
  utils/store.js        采购单与订单
  components/           产品视觉卡、产品卡片
  pages/                10 个页面
```
